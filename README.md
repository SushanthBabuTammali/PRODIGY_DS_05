# PRODIGY_DS_05

## 📊 Task Overview
**Task-05:** Analyze traffic accident data to identify patterns related to road conditions, weather, and time of day. Visualize accident hotspots and contributing factors.

Dataset used: [US Accidents Dataset (Kaggle)](https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents)

---

## 🛠️ Tools & Libraries
- Python
- pandas
- numpy
- matplotlib
- seaborn
- folium / geopandas (for hotspot maps)

---

## 📈 Steps Performed
1. Loaded and explored the US Accidents dataset.
2. Cleaned data (handled missing values, standardized columns).
3. Analyzed accident frequency by:
   - Road conditions
   - Weather conditions
   - Time of day
4. Visualized accident hotspots using geographic mapping.
5. Identified contributing factors and patterns.

---

## 🔍 Insights
- Accidents peak during **rush hours (7–9 AM, 4–7 PM)**.
- Poor weather (rain, snow, fog) significantly increases accident likelihood.
- Road conditions such as wet or icy surfaces correlate with higher severity.
- Hotspot maps reveal dense clusters around **urban highways and intersections**.
